# TradeUp — Clara V2 · IMPLEMENTACIÓN DEL MOCKUP APROBADO

## FUENTE ÚNICA DE VERDAD

Este paquete corresponde a la **versión Clara V2 que fue aprobada visualmente**.

Las imágenes de `/images/` NO son referencias, alternativas ni ejemplos.
**Son los assets definitivos que deben utilizarse en la implementación.**

No sustituyas ninguna fotografía por otra.

## OBJETIVO

Crear una **nueva página/ruta independiente** para Clara V2 a partir de la Landing clara existente.

La versión clara actual debe permanecer intacta.

Ejemplo:
- V1 actual: `/clara.html`
- Nueva V2: `/clara-v2.html`

Si la ruta actual tiene otro nombre, conserva esa ruta y crea una nueva ruta equivalente.

## REGLA ABSOLUTA

**MISMA LANDING + MAYOR IMPACTO VISUAL.**

NO es un rediseño estructural.

Mantener exactamente:
- mismas secciones;
- mismo orden;
- mismo contenido;
- mismos textos;
- misma narrativa;
- mismos módulos/componentes;
- misma navegación;
- mismo formulario;
- misma jerarquía tipográfica;
- mismo comportamiento responsive.

NO agregar secciones.
NO eliminar secciones.
NO agregar contenido.
NO inventar estadísticas.
NO cambiar textos.
NO convertir la página en un nuevo sistema de cards.
NO cambiar la arquitectura para acomodar las fotografías.

## QUÉ SE MODIFICA

Únicamente el tratamiento visual:
- imágenes;
- backgrounds;
- colores;
- iconos;
- texturas;
- overlays;
- máscaras;
- sombras;
- profundidad;
- composición visual dentro de los módulos existentes.

El objetivo es que la página actual se vea como el **mockup aprobado**, sin cambiar su estructura.

## COMPOSICIÓN

Las fotografías pueden integrarse:
- como fondos parciales;
- como imágenes laterales;
- como imágenes de gran formato;
- detrás de contenido existente;
- mediante máscaras;
- mediante degradados suaves;
- como transiciones entre fotografía y blanco.

Pero todo debe suceder **dentro de los módulos existentes**.

No crear módulos nuevos solamente para colocar una fotografía.

## ESTÉTICA

La V2 aprobada utiliza:
- blanco y gris muy claro;
- azul eléctrico TradeUp;
- azul suave;
- fotografía urbana y comercial luminosa;
- sombras suaves;
- líneas finas;
- geometrías sutiles;
- mucho espacio negativo;
- estética corporativa premium;
- sensación contemporánea y aspiracional.

Evitar:
- dark mode;
- colores multicolor;
- neon/cyberpunk;
- glassmorphism excesivo;
- overlays pesados;
- sombras duras;
- exceso de cards;
- fotografías oscuras;
- cambios de estructura.
