# Claude Design — TradeUp Ecuador Light

Usa este paquete como fuente visual para la versión Light.

IMPORTANTE:
1. Lee este documento antes de implementar.
2. Cada fotografía representa una ubicación/contexto distinto de Ecuador. No intercambies imágenes.
3. No generes fotografías nuevas ni sustituyas estos assets.
4. Usa WebP como formato principal y JPG como fallback.
5. Usa `logo/Logo-TradeUp_B1.png` como logo oficial.
6. Mantén la estética Light de la referencia: fondos claros, azul como acento, sombras suaves, fotografía luminosa y premium.
7. No oscurezcas las imágenes con overlays pesados.
8. Usa el hero desktop únicamente en desktop y el hero mobile únicamente en mobile.
9. Los cinco servicios deben usar, respectivamente, tu-02, tu-03, tu-04, tu-05 y tu-06 según el brief.
10. No deformar imágenes; usar object-fit: cover y ajustar object-position cuando sea necesario.

Ubicaciones:
- Hero desktop: Quito / Av. Naciones Unidas / skyline andina.
- Hero mobile: Quito / Centro Histórico.
- DOOH: Aeropuerto Internacional Mariscal Sucre, Quito.
- Vía pública: Malecón 2000, Guayaquil.
- Trade Marketing: Supermaxi, Quito.
- Alianzas comerciales: C.C. Scala Shopping, Quito.
- Soluciones a la medida: Parque La Carolina, Quito.

Antes de terminar, revisa desktop y mobile y confirma que cada bloque utiliza el asset correcto y que ningún texto se sale de su contenedor.
