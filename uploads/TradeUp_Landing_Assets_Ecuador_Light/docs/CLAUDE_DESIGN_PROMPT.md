# TradeUp — Claude Design Integration Prompt
## Ecuador · Light Landing

Usa este paquete como fuente visual principal para la versión LIGHT de la Landing de TradeUp.

### Regla principal
NO generes, busques ni sustituyas fotografías nuevas cuando exista un asset equivalente en este paquete. Usa exactamente los archivos entregados y realiza únicamente recortes, overlays, gradientes y ajustes de integración necesarios.

### Logo
Usar `logo/Logo-TradeUp_B1.png` como logo oficial. No redibujarlo, recrearlo, deformarlo ni reemplazarlo.

### Dirección visual LIGHT
La Landing debe sentirse luminosa, limpia, premium y editorial, tomando como referencia la versión light existente.

Priorizar:
- blanco y grises muy claros
- azul TradeUp como acento
- fotografía clara y contrastada, sin apariencia nocturna dominante
- sombras suaves
- bordes redondeados cuando ya existan en el sistema
- profundidad mediante sombras y fotografía, no mediante bloques negros
- mucho espacio negativo
- fotografías de Ecuador: Quito y Guayaquil, retail y espacios comerciales reales

Evitar:
- fondos negros predominantes
- overlays oscuros pesados
- estética cyber-noir
- neón excesivo
- collages
- ilustraciones
- fotografías de oficina genéricas
- personas posando o mirando a cámara
- logos de terceros innecesarios

### Hero
Usar el hero desktop/mobile correspondiente. `object-fit: cover`. Mantener suficiente área limpia para el titular. El overlay debe ser muy ligero y nunca convertir la fotografía en una imagen oscura.

### Servicios
Cada servicio debe utilizar exclusivamente su fotografía correspondiente. No reutilizar una misma foto entre servicios.

### Texturas
Usar las tres texturas únicamente como fondos sutiles, aproximadamente 5–12% de opacidad, detrás de tarjetas o secciones donde ayuden a dar profundidad. Nunca deben competir con el texto.

### Performance
Preferir WebP y JPG como fallback. No convertir fotografías a PNG. El único PNG principal es el logo.

### Alt sugeridos
- Hero: `Pantalla digital de gran formato en una avenida de Quito.`
- DOOH: `Circuito de pantallas digitales en un terminal de transporte de Guayaquil.`

### Verificación final
1. Desktop y mobile usan sus respectivos headers.
2. Todas las imágenes se ven nítidas y no están deformadas.
3. No existen placeholders.
4. El logo usado es exactamente el entregado.
5. El resultado mantiene el sistema LIGHT de la Landing.
6. El texto conserva contraste y nunca se sale de sus cajas.
7. Las fotografías permanecen visibles y no quedan cubiertas por overlays pesados.
8. La Landing completa se siente como un único universo visual ecuatoriano.
